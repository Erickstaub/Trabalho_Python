# Trabalho_Python
Uma aplicação em Django para a gestão inteligente de salas. O sistema equilibra as necessidades administrativas de organização de infraestrutura com uma interface amigável para que clientes e colaboradores realizem seus agendamentos com facilidade.

A plataforma suporta modelos de reserva gratuitos e pagos, contando com um sistema automatizado de multas para infrações, como cancelamentos fora do prazo ou atrasos na liberação do espaço.
